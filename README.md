# Today-s-Forecast

🌤️ Project Launch: Today’s Forecast – A Real-Time Weather Application

I am pleased to share my recently developed web application, Today’s Forecast, designed to provide accurate and real-time weather information using the WeatherAPI.

🔹 Project Highlights:
• Enables users to search weather conditions for any location
• Displays temperature, humidity, wind speed, and weather conditions with icons
• Integrated background visuals and a video-enhanced results page for improved UI/UX
• Utilizes HTML, CSS, and JavaScript for a clean and responsive interface
• Implements localStorage for smooth data flow between pages
• Includes proper validation and error handling for a seamless user experience
